# BENV0169 Assessment 1 — Task 1

This folder contains the student coding material for **Data quality and energy forecasting for building operation**. The expected workload is approximately 12 hours.

## Start

Create an environment with Python 3.11, open a terminal in this folder, then run:

```text
python -m venv .venv
.venv\Scripts\activate
python -m pip install -r requirements.txt
jupyter lab
```

On macOS/Linux, activate with `source .venv/bin/activate` instead.

Open `assessment_1_task_1.ipynb`, run the supplied setup cells and complete Q1–Q6 in order. The notebook is the assessed coding submission. `assessment_1_task_1_student.py` is an optional plain-text companion for accessibility and version control; it is not a second submission.

Keep the folder structure unchanged and use only repository-relative paths. Implement assessed work in the designated notebook cells, retain the prescribed names and settings, use random seed 42, and do not hard-code missing-data locations or expected scores. Public checks use small synthetic examples and provide feedback only.

Submit the executed notebook and the completed answer form through the coursework submission route described on Moodle. Written answers have a combined 750-word cap: Q1 80, Q2 130, Q3 90, Q4 150, Q5 140 and Q6 160 words.
